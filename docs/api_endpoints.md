# Архитектура демо-API

## Эндпоинты (ручки) для GAME

### Master API

1. Инициализации эксперимента
2. Запрос статуса эксперимента
3. Запуск эксперимента
4. Остановка эксперимента
5. Получение промежуточных результатов
6. Получение результатов экспериментов
7. Список экспериментов

### Runner API

1. Загрузить код эксперимента в problems
2. Запуск эксперимента
3. Остановить эксперимент
4. Получить статус эксперимента
5. Получить визуализацию результатов
6. Получить лучшую программу
7. (опц.) Получить логи
8. (опц.) Healthcheck

## Потенциальные конфигурации Kafka

### Топики

- Получен конфиг эксперимента
- Эксперимент подготовлен
- Эксперимент запущен
- Эксперимент остановлен

### Консьюмеры

- Генератор файлы эксперимента
- Загрузчик файла в Runner
