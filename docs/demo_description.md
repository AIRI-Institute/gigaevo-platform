# Техническое демо

## Последовательность обработки запроса пользователя

- [WebUI -> Master API]: Получили запрос от пользователя на инициализацию эксперимента
- [Master API -> S3]: Сложили данные в S3
- [Master API -> БД]: Сложили данные в БД
- [Master API -> S3]: TASK - Генерируем файлы эксперимента и загружаем в S3
- [Master API -> Runner API]: Запрос на скачивание данных из S3
- [Runner API -> S3]: Скачиваем данные из S3 и складирование в problems
- [Runner API -> Master API]: Заявляем о готовности эксперимента к запуску
- [WebUI -> Master API]: Получили запрос от пользователя на запуск
- [Master API -> Runner API]: Дёргаем ручку запуска эксперимента
- [Runner API]: Запускаем эксперимента
- [Runner API -> Master API]: Отдаём промежуточные данные
- [Master API -> S3]: Загружаем промежуточные данные в S3
- [Master API -> БД]: Загружаем промежуточные данные в БД
- [Master API -> WebUI]: Показывает последние данные
